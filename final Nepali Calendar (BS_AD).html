नेपाली पात्रो · Nepali Calendar

Pending reminder tasks

      Defaults cover fixed-date holidays only. Moon-based festivals (Dashain, Tihar, Holi, Buddha Jayanti, Teej…) change every year: add them from the government notice. If you pick an English date, it is used instead of the BS month/day.

      Date converter

      Backup · Import / Export

      Imports are merged with existing data (duplicates skipped). In Excel files keep BS dates as text like 2083-02-15, and keep the sheet and column names from an export.
      Built-in data: BS 2000–2090 (AD 1943–2034). BS 2000 Baisakh 1 = 14 April 1943. Saturday and Sunday are marked as weekend holidays. Tap any date to add income, expense, reminder tasks, notes or shopping items (coloured dots show what a date holds). Data is stored in this browser’s IndexedDB; use Export to back up. Please verify against the official Nepal government calendar.

      Settings · Month lengths

      Set the number of days (28–32) of each BS month. Quick buttons: 2082, 2083, 2084 and any year you have edited (✎). Saved values are stored in this browser and can be changed again at any time. Dates of later years shift if a year’s total changes.
